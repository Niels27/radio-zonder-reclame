📋 Implementation Overview

The cross-fade system allows smooth transitions between different audio sources (radio, YouTube, Spotify, nonstop radio, lofi girl) by overlapping them for 3-4 seconds during transitions, eliminating abrupt pauses and silence.

🎯 Key Features Implemented:

  • Settings Toggle: "Fade audio streams" option in AdBreakSettings
  • State Management: Cross-fade state tracking and persistence
  • Stream Readiness Detection: Waits for new stream to be ready before fading
  • Volume Control: Smooth volume transitions using fade curves
  • Temporary Overlap: Allows two streams to play simultaneously during fade
  • Fallback System: Immediate switching if cross-fade fails
  • Error Handling: Robust error handling and cleanup

🔧 Core Functions Implemented

1. performCrossFade(oldSourceType, oldProvider, newSourceType, newProvider)

Main orchestrator function that: - Checks if cross-fade is enabled and available - Sets up cross-fade state and volume tracking - Waits for new stream readiness - Executes smooth volume transition - Cleans up old source when complete

2. detectStreamReadiness(sourceType, provider)

Detects when audio streams are ready to play: - Radio: Checks audio element readyState >= 3 - YouTube: Checks player state === YT.PlayerState.PLAYING - Spotify: Checks !player.paused - Floating YouTube: Checks iframe existence

3. setSourceVolume(sourceType, provider, volume)

Controls volume for different audio sources: - Radio: audioRef.current.volume - YouTube: youtubePlayerRef.current.setVolume() - Spotify: setSpotifyVolume() - Handles volume range conversion (0-1 vs 0-100)

🔍 Cross-Fade State Tracking

State Variables:

  • isCrossFading: Boolean indicating if cross-fade is active
  • fadeOldSource: Object tracking the source being faded out
  • fadeNewSource: Object tracking the source being faded in
  • fadeStartTime: Timestamp when fade began
  • oldSourceVolumeRef: Real-time volume of fading out source
  • newSourceVolumeRef: Real-time volume of fading in source

🛡️ Error Handling & Robustness

Safety Mechanisms:

  • Readiness Timeout: Falls back to immediate switch if new stream doesn't become ready
  • Fade Timeout: Cleanup after maximum fade duration + buffer
  • Interval Cleanup: Prevents memory leaks from fade intervals
  • Volume Restoration: Ensures new source reaches full volume
  • State Reset: Clears cross-fade state on completion or error
  • Single-Stream Enforcement: Old source is stopped after fade completes
